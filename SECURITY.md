# Security policy

Please report security problems privately, not in a public issue: use **Report a
vulnerability** on this repository's Security tab (GitHub private vulnerability reporting).

Include the image's build ID (shown on **System → Firmware**) and, if you can, the steps to
reproduce. This is a hobby project, so there's no formal response time, but reports are
welcome and will be taken seriously.

Only the latest image is supported. What the image defends against, what was tested, and the
known residual risks are in [docs/security.md](docs/security.md).
